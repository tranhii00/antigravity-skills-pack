# 🚀 Antigravity Skills & MCP Full Pack

Trọn bộ **38 Skills chuyên sâu** và **3 MCP Servers** mạnh mẽ dành cho **Google Antigravity**, được tổng hợp và cấu hình sẵn giúp nâng cấp trợ lý AI của bạn lên mức tối đa.

---

## 📦 Danh Sách Các Thành Phần

### 🎨 1. Thiết Kế, UI/UX & Frontend
- **ui-ux-pro-max**: Trí tuệ thiết kế UI/UX toàn diện (50+ style, 161 bảng màu, 57 cặp font, quy tắc WCAG).
- **frontend-design**: Xây dựng giao diện web độc đáo, chuẩn production, tránh phong cách AI chung chung.
- **interface-design**: Thiết kế giao diện chuyên sâu cho dashboard, admin panel, SaaS.
- **baseline-ui**: Chuẩn hóa animation, typography và kiểm tra accessibility cho Tailwind CSS.
- **make-interfaces-feel-better**: Tinh chỉnh chi tiết micro-interactions, hover states, border-radius, shadows.
- **canvas-design**: Thiết kế poster, ấn phẩm đồ họa tĩnh dạng PNG/PDF chất lượng cao.
- **theme-factory**: Bộ công cụ áp dụng 10 theme thiết kế chuyên nghiệp.
- **web-artifacts-builder**: Tạo các artifact web đa thành phần (React + Tailwind + shadcn/ui).
- **webapp-testing**: Tự động hóa kiểm thử web ứng dụng qua Playwright (chụp ảnh, xem log).
- **fixing-accessibility**: Kiểm tra và sửa lỗi trợ năng (WCAG, ARIA labels, focus, contrast).
- **fixing-metadata**: Tối ưu SEO metadata, Open Graph tags, JSON-LD.
- **fixing-motion-performance**: Tối ưu hiệu năng animation, chống giật lag layout.
- **algorithmic-art**: Sáng tạo nghệ thuật thuật toán với p5.js.
- **slack-gif-creator**: Tạo ảnh động GIF tối ưu hóa cho Slack.

### 🏷️ 2. Bộ Nhận Diện & Thiết Kế Thương Hiệu (CKM)
- **ckm:design**: Thiết kế toàn diện (Logo AI 55 styles, CIP 50 ấn phẩm, slides, banner, icon).
- **ckm:design-system**: Xây dựng hệ thống design tokens 3 lớp và quy chuẩn component.
- **ckm:ui-styling**: Thiết kế giao diện với shadcn/ui và Tailwind CSS.
- **ckm:banner-design**: Thiết kế banner đa nền tảng (Facebook, X, YouTube, Ads, Web hero).
- **ckm:brand**: Quản lý tiếng nói thương hiệu và quy chuẩn hình ảnh.
- **ckm:slides**: Tạo slide thuyết trình HTML tương tác với Chart.js.
- **brand-guidelines**: Áp dụng chuẩn màu sắc và typography nhận diện.

### 📄 3. Xử Lý Tài Liệu & Văn Phòng
- **xlsx**: Mở, tạo, xử lý công thức và định dạng file bảng tính Excel (.xlsx, .csv).
- **docx**: Tạo, đọc, biên tập báo cáo và tài liệu Word (.docx).
- **pdf**: Đọc, trích xuất text/bảng biểu, gộp/tách, điền form PDF.
- **pptx**: Tạo, đọc và biên tập slide PowerPoint (.pptx).
- **doc-coauthoring**: Hướng dẫn quy trình đồng sáng tác tài liệu kỹ thuật, đề xuất (RFC, PRD).
- **internal-comms**: Soạn thảo tài liệu truyền thông nội bộ, cập nhật dự án, báo cáo tuần.

### 💻 4. Phát Triển Phần Mềm, Quy Trình & Kiểm Thử
- **tdd**: Lập trình hướng kiểm thử (Test-Driven Development) chu trình Red-Green-Refactor.
- **diagnose**: Quy trình chẩn đoán lỗi khó và sụt giảm hiệu năng (Reproduce -> Hypothesise -> Fix).
- **improve-codebase-architecture**: Tìm kiếm cơ hội tối ưu kiến trúc mã nguồn.
- **prototype**: Xây dựng nguyên mẫu nhanh (terminal app hoặc UI toggle).
- **claude-api**: Tối ưu ứng dụng sử dụng Claude API và Anthropic SDK (Prompt caching).
- **mcp-builder**: Hướng dẫn xây dựng MCP server chất lượng cao (Python / Node.js).
- **triage**: Quản lý và phân loại issue/bug theo quy trình state machine.
- **to-prd**: Chuyển đổi ngữ cảnh trò chuyện thành PRD hoàn chỉnh.
- **to-issues**: Phân tách kế hoạch/PRD thành các issue độc lập trên issue tracker.
- **handoff**: Đóng gói ngữ cảnh trò chuyện hiện tại thành tài liệu chuyển giao cho agent khác.

### ⚙️ 5. Tạo & Tùy Biến Trợ Lý
- **skill-creator**: Tạo mới, tối ưu và đo lường hiệu năng của agent skill.
- **write-a-skill**: Hướng dẫn cấu trúc skill chuẩn mực với progressive disclosure.
- **grill-me**: Phỏng vấn phản biện sâu về bản thiết kế/kế hoạch để làm rõ quyết định.
- **grill-with-docs**: Phản biện kế hoạch dựa trên tài liệu kiến trúc (ADR, CONTEXT.md).
- **caveman**: Chế độ giao tiếp siêu cô đọng, tiết kiệm token tối đa.

## 🛠️ Hướng Dẫn Cài Đặt (Cho Bạn Bè)

### Cách 1: Tải Về & Copy Vào Thư Mục Antigravity (Khuyên Dùng)

1. Tải toàn bộ mã nguồn repo này về máy (hoặc tải file ZIP).
2. **Cài đặt Skills:**
   - Copy thư mục `skills` và dán vào:
     ```text
     C:\Users\<Tên_User_Của_Bạn>\.gemini\antigravity\skills
     ```
     *(Nếu chưa có thư mục `skills` thì tạo mới).*
3. **Cài đặt MCP Servers:**
   - Copy file `mcp_config.json` và dán đè vào:
     ```text
     C:\Users\<Tên_User_Của_Bạn>\.gemini\antigravity\mcp_config.json
     ```
   - *Yêu cầu:* Máy tính đã cài đặt [Node.js](https://nodejs.org/).
4. **Khởi động lại Antigravity:** Tắt hoàn toàn ứng dụng và mở lại để hệ thống kích hoạt toàn bộ tính năng.

---

### Cách 2: Dùng Riêng Cho 1 Dự Án Cụ Thể

Nếu chỉ muốn dùng cho 1 dự án hiện tại:
1. Mở thư mục dự án của bạn trong Antigravity.
2. Tạo thư mục `.agents` ngay tại gốc dự án.
3. Copy thư mục `skills` thả vào bên trong `.agents`:
   ```text
   <Thư_Mục_Dự_Án>\.agents\skills\
   ```
